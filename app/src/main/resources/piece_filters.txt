# Piece filter definitions.
#
# Three levels: a filter-set (this file's top-level, unindented keys) contains one or more
# filters (indented keys), and each filter contains one or more subfilters (indented "- "..."
# lines). Selecting a filter-set from the Filters menu starts at its first filter's first
# subfilter; stepping forward reveals subfilters[0..N] within the current filter, and once
# you're past its last subfilter, stepping forward again moves into the *next* filter in the
# set, starting fresh at ITS subfilter 0 -- a filter's own accumulated pieces do not carry over
# into the next filter, so pieces can disappear once you've moved past the filter that revealed
# them, unless that next filter's own subfilters re-include them.
#
# Cell letters: U D L R F B I O -- a piece matching a cell letter touches that cell.
# Type letters: m r e c -- Centers(1 sticker) / Ridges(2) / Edges(3) / Corners(4).
# Comma-separating tokens within one subfilter is a union.
# Within one token, a "-" splits off pieces to remove, e.g. "mre-LR" = every center/ridge/edge
# piece, except any touching L or R -- chainable ("mre-L-R" removes the same thing).
# On either side of a "-": cell letters concatenated together are an intersection (piece must
# touch all of them), optionally narrowed to one type by a single trailing type letter (e.g.
# "IUFe" = the one piece touching I, U, and F that's also an edge). A BARE run of only cell
# letters (no type letter), or only type letters, is a union instead (e.g. "LR" = touches L or
# R; "mre" = a center, ridge, or edge) -- intersecting same-category letters would always be
# empty (no piece touches two opposite cells, or is more than one type at once), so that
# combination means "any of these" instead.
#
# A leading "+" on a subfilter (e.g. "+r") means "add this to whatever was visible one step
# ago" instead of the default, which clears everything visible before applying this subfilter's
# own matches -- the same rule whether the previous step was another subfilter in this filter,
# or the last subfilter of the previous filter in this filter-set. That's what lets a filter's
# label change without clearing its pieces (or vice versa) -- they're no longer tied together.
